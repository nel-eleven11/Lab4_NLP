# Laboratorio 4 — NLP

## Entregables

- `laboratorio_4.ipynb`: notebook ejecutado con análisis de sentimiento, NER, análisis de cinco casos difíciles y respuestas de reflexión.
- `laboratorio_4_dataset.csv`: dataset simulado de 30 reseñas.
- `laboratorio_4_resultados.csv`: predicciones integradas para las 30 reseñas; las entidades están serializadas como JSON.

## Archivos complementarios

- `laboratorio_4_entidades.csv`: menciones NER en formato tabular.
- `laboratorio_4_resumen_sentimiento.csv`: cantidad y score promedio por etiqueta.
- `laboratorio_4_resumen_general.csv`: indicadores globales.
- `laboratorio_4_menor_confianza.csv`: cinco reseñas con menor score de sentimiento.
- `laboratorio_4_tipos_entidad.csv`: conteo de menciones por tipo NER.

El dataset es simulado y las predicciones no son etiquetas gold ni una evaluación de exactitud.
